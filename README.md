# Software Knowledge Base

[//]: # "addons"

## Available addons

| **Addon**                                                                                 | **Summary**                                                                       |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| [software_knowledge_base](software_knowledge_base/)                                       |  A module for maintaining data regarding software installations and modules.      |
| [software_knowledge_base_classification](software_knowledge_base_classification/)         |  Adds classifications to Software knowledge base installations.                   |
| [software_knowledge_base_contracts](software_knowledge_base_contracts/)                   |  Adds contracts/contract line to SDKB.                                            |
| [software_knowledge_base_technical_contacts](software_knowledge_base_technical_contacts/) |  Link technical contacts to SKDB data.                                            |
| [software_knowledge_base_website_polling](software_knowledge_base_website_polling/)       |  Allows auto-polling whether installation websites are up.                        |
| [software_knowledge_base_vc](software_knowledge_base_vc/)                                 |  Adds version control integration to Software development knowledge base          |
| [software_knowledge_base_vc_odoo](software_knowledge_base_vc_odoo/)                       |  Adds Odoo-spesific tools for Software development knowledge base version control |
